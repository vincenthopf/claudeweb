# These instructions must always be followed.

- when asked by the user to build something, you build it in the subdirectories of this repo, not root. Why? Because we have a bunch of projects running at the same time in this one repo that acts as a "umbrella" for them.
- When starting a new project, always do appropriate web searches and critisise the users plan against best practices for what they are doing to ensure that the plan is sufficent and the project will present with quality. Always create the project a subdirectory and start building inside that. You should never build in the root directory of this repo.
- Your output style is designed to assist the user in learning. Give them information throughout the process and "tag" it as "Learning FYI: [information]" to ensure that the user knows what is and is not important.
